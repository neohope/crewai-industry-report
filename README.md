# 行业研究报告生成系统

基于CrewAI的多代理协作行业研究报告生成系统 - **完整可工作实现**

## 🌟 系统特点

- **7个专业代理** - 完整的角色分工和职责定义
- **4阶段工作流程** - 并行采集 → 验证分析 → 撰写审核 → 飞书发布
- **智能质量控制** - 95分以上通过标准，最多3次迭代优化
- **真实工具集成** - 网络搜索、新闻搜索、飞书文档/消息
- **完整测试套件** - 多层级验证，确保功能可用

## 🚀 快速开始

### 前置要求

- Python 3.10 或更高版本
- OpenAI API Key
- （可选）飞书 API 凭证

### 1. 验证项目结构

首先运行无依赖的快速检查：

```bash
python check.py
```

### 2. 安装依赖

使用 Poetry（推荐）：

```bash
poetry install
```

或使用 pip：

```bash
pip install -r requirements.txt
```

### 3. 配置环境

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件，填入你的配置
# 必需：OPENAI_API_KEY
# 可选：LARK_APP_ID, LARK_APP_SECRET, LARK_RECEIVER_ID
```

### 4. 运行完整测试套件

**这是最重要的验证步骤，确保所有功能正常：**

```bash
python run_all_tests.py
```

### 5. 运行单个测试

也可以单独运行各部分测试：

```bash
# 测试搜索工具
python test_search_tools.py

# 测试飞书工具
python test_feishu_tools.py

# 测试主程序
python test_crew.py
```

### 6. 运行完整工作流

```bash
# 使用 Poetry
poetry run python src/main.py

# 或直接运行
python src/main.py
```

## 📖 详细使用指南

### 代理角色说明

#### 1. 数据采集员 × 3
- **采集员1**: 市场规模、增长趋势、市场份额、区域分布
- **采集员2**: 技术发展、创新动态、研发投入、应用案例
- **采集员3**: 主要企业、产品服务、竞争策略、近期动态

#### 2. 数据分析师
- 交叉验证多源数据
- 清洗去重、标注可信度（高/中/低）
- 整合结构化数据集
- 列出存疑数据点及原因

#### 3. 报告撰写师
- 撰写专业行业研究报告（7个章节）
- 根据反馈迭代优化
- 输出 Markdown 格式报告

#### 4. 报告评价师
- 多维度质量评分（100分制）
  - 内容详实性：30分
  - 逻辑性：30分
  - 可靠性：25分
  - 可读性：15分
- 95分以上通过，否则给出具体修改意见

#### 5. 报告发布师
- 发布到飞书文档
- 发送消息通知
- 本地文件备选方案

### 工作流程详情

#### 阶段1: 并行数据采集
- 3位采集员同时工作
- 使用真实网络搜索工具
- 结构化数据输出

#### 阶段2: 数据验证与分析
- 分析师处理采集到的所有数据
- 交叉验证、清洗去重
- 可信度标注

#### 阶段3: 报告撰写与审核循环
- 撰写 → 审核 → 修改
- 最多3次迭代
- 直到评分≥95分

#### 阶段4: 报告发布
- 飞书文档发布
- 消息通知
- 本地文件保存

### 问题: 找不到模块


```bash

```
